# 🧬 DNA Analyzer (Python Bioinformatics Project)

This project analyzes DNA sequences using Python.

## 🔍 Features
- DNA → RNA transcription
- Reverse & Reverse Complement
- Base count (A, C, G, T)
- GC Content & AT Content
- Sequence length calculation
- Input validation
- Graph visualization (base percentages)
- Final summary (average GC content)

## 📂 Input
A text file (`dna.txt`) containing DNA sequences:
AGTCA
TTGCA
GGGAA
## 📊 Output
- Printed analysis in terminal
- Graph images saved as `.png`

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
